PROJECT // SCOUT

On-Device Visual Assist Companion

VERIFIED METRIC 150ms Street Inference
MISSION

Build an ultra-fast visual interpreter for blind users that bypasses iOS native install barriers.

OBSERVATIONS

VoiceOver delays and cloud-roundtrip latencies (2-4 seconds) cause low-vision users to drop off assistive platforms quickly.

SYSTEM ARCHITECTURE

Implemented a browser-native inference hierarchy: Tier 1 executes object classification locally in WebGL via TensorFlow.js COCO-SSD (80-120ms); Tier 2 processes document OCR on-device; Tier 3 routes only complex visual queries to Gemini 1.5 Flash. Bypassed iOS browser SpeechSynthesis autoplay gates using a cyclic user-triggered dummy audio context.

PROJECT // PRISM

Capability-Gated Agent Proxy

SECURITY STATE Deterministic Shell Interceptor
MISSION

Enforce strict least-privilege capability gates on autonomous coding agents (Claude SDK) inside VS Code workspaces.

OBSERVATIONS

Prompting directives are easily subverted or ignored. Coding agents need hardware/process level security boundaries.

SYSTEM ARCHITECTURE

Built a security middleware proxy in TypeScript. The system intercepts agent tool executions (e.g. file writes, shell tasks) before process evaluation, mapping calls against a strict schema. Flagged executions prompt the user with interactive approval webviews.
