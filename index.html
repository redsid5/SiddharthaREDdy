Featured Product

Scout

Real-time edge visual companion for blind users.

SHIPPED DATE June 2026
CORE METRIC 150ms latency / 75% on-device
LINKS
Live app ↗ GitHub ↗
Problem

Blind and low-vision individuals face severe lag (2–4 seconds) with cloud-reliant assistive vision apps, making active navigation unsafe. Native mobile SDKs also erect high download barriers for transient tasks.

Research & User Validation

Interviewed 20+ low-vision users to study assistive flows. Discovered that system latency and audio interruptions from screen readers (VoiceOver) were the primary drop-off triggers.

Hypothesis & Technology

By building a client-side execution hierarchy (Tier 1: TensorFlow.js COCO-SSD running in browser WebGL, Tier 2: local OCR, Tier 3: cloud LLM fallback), we could handle 70%+ of simple scans locally under 150ms.

Research Prototype

PRISM

Gated capability security proxy for coding agents.

SHIPPED DATE May 2026
STATUS Code Sandbox Verified
LINKS GitHub Private (Academic/Patent Review)
Problem

Autonomous VS Code agents (like Devin) possess direct shell and filesystem execution blocks. Standard text-based system prompts fail to prevent malicious bash commands or accidental local directory wipes.

Hypothesis & Build

We hypothesized that security must be enforced in the runtime execution engine rather than the LLM context. Built a TypeScript proxy layer that intercepts agent calls, matches them against a user-defined capability list, and flags non-allowlisted actions for prompt authorization.

Lessons Learned

Multi-agent setups require isolation at the process sandbox boundary (gRPC loops). Prompt guidelines are easily bypassed, but strict syntax checking at the shell proxy guarantees security.

Thinking & Field Notes

// System design observations and product strategy critiques

OBSERVATION 01 • JULY 2026

Prompt Gating is a Leaky Security Model

Relying on system prompts (e.g. "Do not delete files") to prevent agent execution failures is unsafe. AI agents process guidelines probabilistically. True runtime security must be gated by deterministic process interceptors that intercept actual API calls and bash commands, completely separate from the LLM execution thread.

OBSERVATION 02 • MAY 2026

Designing for the Edge: A Latency First Approach

For transient user flows (like street navigation), loading a heavy mobile app is a friction point. However, web workers running lightweight on-device TF.js models achieve sub-150ms classifications. A hybrid pipeline (local detection falling back to cloud APIs only when accuracy drops) optimizes user latency while protecting cloud operating budgets.
